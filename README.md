# Bible Reader

A simple Bible Web app for a focused reading experience. :coffee:

## What it does

- Ancient Scripture Exploration Facilitation
- Written as an example project with Duck.AI :coffee:

## How to run

```bash
git clone https://github.com/Portalwalker/BibleReader_SpringBootEdition.git
cd BibleReader_SpringBootEdition
./startapp
```

### Note
- You may need to authenticate to sudo in order to start the postgresl service.
- Supported Platforms: Linux

### Requirements
- maven
- postgresql
- npm
- git
- bash terminal
